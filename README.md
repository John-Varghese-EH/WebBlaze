# 🔥 WebBlaze

> **An open-source, high-performance web auditing tool with a brutalist, high-contrast aesthetic.**

WebBlaze strips away the marketing fluff to expose the brutal truth about your web performance, security, and AI visibility. No sugarcoating, just raw data.

## ⚡ Features

*   **Real-time Web Auditing:** Analyzes TTFB, Load Time, Page Weight, and Security Headers.
*   **AI Visibility Dashboard:** Evaluates if engines (Google, Claude, ChatGPT, etc.) can interpret your site effectively based on MRR (Machine Readability Ratio) and semantic signals.
*   **Brutalist Design System:** High-tech minimalist UI featuring Ultra-dark backgrounds (`#050505`), Brand Red (`#F85149`), and Neon Green (`#39FF14`).
*   **Hall of Fame & Shame:** Global score distribution chart using `recharts` to track top performers and the embers that need rescue.
*   **Session History:** Keeps track of your recent scans with sparkline trend indicators using browser local storage.
*   **Full-Stack Architecture:** Powered by a React SPA and an Node.js/Express backend for fast server-side processing.

## 🛠 Tech Stack

*   **Frontend:** React 19, TypeScript, Tailwind CSS v4, Lucide React, Recharts
*   **Backend:** Node.js, Express
*   **Build Tool:** Vite, esbuild
*   **Typography:** Inter (UI), JetBrains Mono (Data/Tech)

## 🚀 Getting Started

### Prerequisites

Ensure you have Node.js (v18+) installed.

### Installation

1.  Clone the repository:
    ```bash
    git clone https://github.com/John-Varghese-EH/webblaze.git
    cd webblaze
    ```

2.  Install dependencies:
    ```bash
    npm install
    ```

3.  Start the development server:
    ```bash
    npm run dev
    ```

4.  Build for production:
    ```bash
    npm run build
    npm run start
    ```

## 🧠 Why WebBlaze?

Standard performance tools are great, but they often hide the underlying impact your site has on modern LLMs and generative search engines. WebBlaze combines traditional performance metrics with an **AI Authority & Citability** score to ensure your content is indexable by bots and properly synthesized by modern AI models.
